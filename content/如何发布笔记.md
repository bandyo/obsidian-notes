# 如何发布笔记

这个网站的源文件就是一个 Obsidian 库，位置在项目的 `content/` 文件夹。

## 日常流程

1. 用 Obsidian 打开 `content` 文件夹作为库。
2. 像平常一样写笔记，支持 [[Obsidian 快捷技巧|双向链接]]、标签、callout 等语法。
3. 在终端执行：

```bash
npx quartz sync
```

> [!tip] 发生了什么
> `sync` 会提交 `content/` 里的改动并推送到 GitHub，随后 GitHub Actions 自动构建并发布网站，通常 1 分钟内生效。

如果只想先本地预览：

```bash
npx quartz build --serve
```

然后打开 http://localhost:8080
