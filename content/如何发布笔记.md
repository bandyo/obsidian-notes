# 如何发布笔记

这个网站的源文件就是一个 Obsidian 库，位置在项目的 `content/` 文件夹。

## 日常流程

1. 用 Obsidian 打开 `content` 文件夹作为库（已注册到 Obsidian 的库列表，直接选「我的笔记」即可）。
2. 像平常一样写笔记，支持 [[Obsidian 快捷技巧|双向链接]]、标签、callout 等语法。
3. 保存后，双击项目根目录的 `sync.bat`（或在终端运行 `node sync.mjs`）。

> [!tip] 发生了什么
> 脚本会把 `content/` 里的新增、修改、删除同步到 GitHub 的 `v5` 分支，然后自动构建并发布到网站，通常 1 分钟内生效。全程走 GitHub API，不需要 Git 推送。

如果只想先本地预览：

```bash
npx quartz build --serve
```

然后打开 http://localhost:8080
